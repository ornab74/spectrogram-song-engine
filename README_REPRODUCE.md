# Reproducing the spectrogram + quantum-inspired RGB experiment

This bundle contains the actual original scripts and saved result files from the audio/songwriting workflow and a later research paper explaining them. It includes the WAV as a self-contained research input.

## What was actually executed

- `analyze_audio.py` was used to produce `track_analysis.json` and `track_spectrogram.png` from the user WAV.
- `quantum_rgb_entropy.py` was used to produce `quantum_rgb_entropy_results.json` and its image/rhyme palette.
- On 2026-10-16 the circuit was rerun with the same WAV and produced a byte-for-byte identical results JSON (`quantum_rgb_entropy_recheck.json`).
- The final creative drafting used this palette and tempo/arrangement guide, but is **not** deterministically generated by the Python scripts.

## Environment verified during paper preparation

Python with NumPy 2.3.5, SciPy 1.17.0, librosa 0.11.0, soundfile 0.13.1, and Matplotlib 3.10.8. The `requirements_verified.txt` file lists these package versions.

## Inputs and commands

The entropy script is portable:

```bash
python quantum_rgb_entropy.py \
 'Punchier Pre-Chorus and Chorus (Extended) (1) (1) (1).wav' \
 --json quantum_rgb_entropy_results.json
```

The original `analyze_audio.py` is *not* command-line configurable; it contains `/mnt/data/` absolute paths and specifically assumes a 48 kHz WAV, downsampled by four. To run it unchanged, put the input at the exact hard-coded path and run `python analyze_audio.py` in that environment. To run elsewhere, modify `p` and the output paths and change the resampling ratio if using a different sample rate. This is an explicit legacy limitation, not a hidden option.

## Scientific interpretation

The three-qubit statevector is simulated on a regular computer using NumPy and analytic Born-rule probabilities. The 4,096 “shots” are seeded NumPy categorical draws, not hardware quantum measurements. Entropy is uncertainty over eight outcomes, not a demonstrated increase in lyric quality. The two recurring images were derived from the selected top two outcomes of a hand-curated motif bank.

The exact intermediate private drafting prompts are not stored and are not claimed to be recovered. The document includes the original recorded user request, final Suno Style text, saved Lyrics field, and a separately labeled reconstruction prompt for independent repetition of the creative stage.
